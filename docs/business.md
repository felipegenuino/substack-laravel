# Business Rules – Content Platform

## Content Visibility

- Public + Published: visible to everyone
- Private + Published: only authenticated users
- Draft: only author

## Content Types

- post: long-form article
- note: short text, title optional
- video: external video link + description
- tutorial: structured long-form content

## Comments

- Allowed only on Published content
- Only authenticated users can comment
- No moderation system in MVP

## Taxonomies

- Categories are hierarchical
- Tags are flat
- Content can have multiple categories and tags
