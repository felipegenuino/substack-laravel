# Roadmap – Content Platform (Substack-like)

This roadmap represents intended evolution.
Dates are indicative. Scope may change.

---

## Phase 0 — Foundation (MVP Core) ✅

Goal: Have a usable personal publishing platform.

- [x] Laravel + Livewire + Volt setup
- [x] SQLite database
- [x] Authentication (built-in)
- [x] Content model (post, note, video, tutorial)
- [x] Public / Private visibility
- [x] Draft / Published states
- [x] Markdown rendering
- [x] Basic comments (authenticated only)
- [x] Categories and tags
- [x] Public feed + single content page
- [x] Author dashboard

Non-goals:

- Payments
- Emails
- Subscriptions
- Reactions

---

## Phase 1 — Writing Experience ✅

Goal: Make writing enjoyable.

- [x] Better markdown editor (preview, shortcuts)
- [x] Autosave drafts
- [x] Content scheduling
- [x] Notes‑first UX (lighter layout)
- [x] Keyboard-first navigation

---

## Phase 2 — Reading Experience

Goal: Improve consumption and discovery.

- [ ] Archive by month/year
- [ ] Category and tag pages
- [ ] Better typography presets
- [x] Reading time estimation
- [x] Dark mode

---

## Phase 3 — Private Content & Access

Goal: Prepare for selective access.

- [ ] Invite-only users
- [ ] Private collections
- [ ] Content visibility by role
- [ ] Simple access rules (not payments yet)

---

## Phase 4 — Monetization (Optional / Future)

Goal: Validate paid content ideas.

- [ ] Paid posts
- [ ] Free vs paid feed
- [ ] Stripe integration
- [ ] Subscriber roles
- [ ] Simple paywall

---

## Phase 5 — Newsletter (Optional)

Goal: Expand distribution.

- [ ] Email sending
- [ ] Subscriber list
- [ ] Post-to-email
- [ ] Email preferences

---

## Ideas (Not Committed)

- Reactions / likes
- Highlights
- Public profiles
- RSS feeds
- Import from WordPress
