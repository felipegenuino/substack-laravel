# Project – Substack Clone (MVP)

## Objective

Build a minimal Substack-like platform using Laravel, Livewire and SQLite.

## Stack

- Laravel
- Livewire + Volt
- Blade + Tailwind
- SQLite
- Pest
- Lucide Icons

## Core Concepts

- Single Content model (post, note, video, tutorial)
- Public / Private visibility
- Draft / Published states
- Markdown-based content
- WordPress-like taxonomies (categories + tags)

## Non-goals (for MVP)

- Payments
- Email newsletter sending
- Multi-tenant
- Reactions / likes

## Architectural Decisions

- Use SQLite for simplicity
- Use Livewire instead of SPA
- Avoid over-abstraction
